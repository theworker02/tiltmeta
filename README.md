# tiltmeta

Tilt URLs and meta query parts with stable normalization.

**Site:** https://theworker02.github.io/tiltmeta/

## Install / run

```bash
git clone https://github.com/theworker02/tiltmeta.git
cd tiltmeta
node src/cli.js
node --test
```
